# claudeexperiment

This repository hosts the **Odoo Master** Claude Code plugin and its marketplace.

- Plugin: [`odoo-master-plugin/`](odoo-master-plugin/README.md)
- Marketplace manifest: [`.claude-plugin/marketplace.json`](.claude-plugin/marketplace.json)
- Research: [`docs/research/`](docs/research/) — reference plugin comparison and Odoo 16–20 technical research

Install:
```
/plugin marketplace add shonejj/claudeexperiment
/plugin install odoo-master@odoo-master
```
